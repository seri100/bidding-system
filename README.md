\# 📋 공고 검색 시스템 (Bid Announcement Search System)



\## 개요



입찰 공고를 효율적으로 관리하고, 등록된 회사의 적격성을 자동으로 평가하는 웹 기반 시스템입니다.



\*\*주요 기능:\*\*

\- 📊 입찰 공고 검색 및 필터링

\- 📈 기관별/공종별/지역별 통계 대시보드

\- 🏢 회사 정보 관리

\- ⭐ 자동 적격성 평가 (재무, 경험, 신용 점수)



\---



\## 시스템 요구사항



\- \*\*OS\*\*: Windows 10/11

\- \*\*Node.js\*\*: v20.0 이상

\- \*\*MongoDB\*\*: v4.4 이상 (로컬 설치)

\- \*\*브라우저\*\*: Chrome, Edge, Firefox (최신 버전)
