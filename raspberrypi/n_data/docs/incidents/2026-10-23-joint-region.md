# 2026-10-23 공동도급지역 누락

## 증상과 의미

양산 공공임대형 지식산업센터 소방공사 `R26BK01789188-000` 알림에 비율 49%가 있는데 공동도급지역은 공란이었다. API의 지역의무공동도급 비율/여부는 있어도 `jntcontrctDutyRgnNm1~3`가 비어 있는 경우였다.

공동도급 의무지역과 참가가능지역은 다른 값이다. 현장이나 발주기관의 소재지로 공동도급지역을 채우지 않았다.

## 실패했던 접근과 원인

- 라즈베리파이의 Desktop Commander 원격 실행은 Node 18의 native WebSocket 부재로 실패했다. 설치한 Node 22 실행 파일도 Raspbian 10의 `GLIBCXX_3.4.26` 부재로 동작하지 않았다. 시스템 라이브러리를 교체하지 않고 기존 PC 연결을 통한 SSH 작업으로 전환했다.
- Selenium/Chromium 자체 동작 검사는 약 1.8초, 나라장터 기본 HTTP 접속은 약 0.74초였다. 인터넷이나 브라우저 전체가 항상 느린 상태라는 결론은 내리지 않았다.
- 메인 화면의 `Go to slide 2`에는 배너 요소도 있다. 실제 검색 전환 요소를 구분해야 했다. 마우스 클릭은 최근 본 화면 패널에 가려지는 경우가 있어 Enter를 사용했다.
- 검색 종류를 통합상세로 명시하지 않으면 숨겨진 다른 검색 폼의 입력칸을 선택할 수 있었다. `_totBizNo`와 `_btnUntyDtlSrch`를 사용했다.
- 결정적인 상세 진입 오류는 제목 바깥 td를 클릭하던 점이었다. 실제 공고 제목인 `label[id$='_bizNm']` 클릭으로 해결했다. 뒤늦게 표시되는 공지 팝업도 진입 전에 정리했다.
- 실패 시험을 셸 timeout으로 종료하면서 ChromeDriver 2개가 남은 것을 확인해 해당 시험 프로세스와 하위 브라우저만 정리했다. 이후 시험은 별도 프로세스 그룹과 시간 제한으로 종료했다.

## 적용한 변경

`g2b_joint_region.py`를 추가하고 `main_send.py`에서 수신자 판정 전에 보완한다. 기존 서울 공고번호 고정 보정을 제거했다. 원문과 정규화 행을 함께 갱신하고, 여러 공동도급지역을 알림톡에 모두 표시하도록 포맷터를 수정했다.

동일 공고번호·차수의 상세화면에서 공동도급지역·지역의무공동도급 여부·비율을 읽는다. 값이 충돌하거나 필수가 누락되면 성공으로 처리하지 않는다.

1회 최대 1건, 전체 브라우저 작업 240초, 성공 캐시 6시간이다. 실패 건은 NAS 상태 파일의 대기열로 보내 빈 지역 알림으로 중복가드가 소진되지 않도록 보류한다. 다음 실행에서 재시도하며 입찰 마감 또는 7일이 지난 대기는 제거한다.
